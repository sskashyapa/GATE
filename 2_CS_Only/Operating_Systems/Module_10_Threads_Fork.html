🧵 Module 10: Threads & Fork()

Lightweight Processes, User vs Kernel Threads, and the Fork System Call

📖 Core Fundamental Theory: Why Threads?

A Process is a "heavyweight" execution unit. It has its own isolated memory space, code, and data. Creating a new process takes a lot of time and memory. If a web server created a brand new Process for every single user request, the RAM would crash instantly.

The Solution: Threads ("Lightweight Processes"). A Thread is the smallest sequence of programmed instructions that can be managed independently by the OS scheduler. Multiple threads can exist inside the same process.

What do Threads SHARE vs KEEP PRIVATE?

SHARED (with other threads in the process):
  • Code Section
  • Data Section (Global Variables)
  • Open Files (OS resources)
PRIVATE (Unique to each thread):
  • Program Counter (PC)
  • CPU Registers
  • Stack Memory (Local Variables)

2️⃣ User-Level vs Kernel-Level Threads

Threads can be implemented in the User Space (by a programming library like Java Threads) or directly in the Kernel Space (by the OS itself like Windows/Linux threads).

Feature User-Level Threads (ULT) Kernel-Level Threads (KLT)
OS Awareness OS doesn't know they exist. Sees them as 1 process. OS fully manages and schedules them.
Creation Speed Very Fast (No system calls needed) Slower (Requires System calls)
Blocking Issue If 1 thread blocks (e.g. waits for I/O), the OS blocks the ENTIRE process! If 1 thread blocks, other threads keep running.

3️⃣ The fork() System Call

fork() is a system call used in UNIX to create a brand new process. The new process is an exact copy (a clone) of the parent process, called the Child Process.

The Return Values of fork():

When you call fork(), it happens once, but it returns twice!

  • Returns > 0 (the child's Process ID) to the Parent Process.
  • Returns 0 to the newly created Child Process.
  • Returns -1 if the creation failed.
int pid = fork(); if (pid == 0) { printf("I am the Child Process!"); } else if (pid > 0) { printf("I am the Parent Process! My child is %d", pid); }

4️⃣ The fork() Math (GATE Numericals)

If fork() is called N times in a row:

Total Processes = 2N

Child Processes = 2N - 1

// Example: N=3
fork(); // 2 processes total
fork(); // 4 processes total
fork(); // 8 processes total

Total Processes = 23 = 8
Child Processes = 8 - 1 = 7

⚠️ GATE TRAP: The AND / OR short-circuit

GATE loves to ask questions like: if(fork() && fork()).

Because it is a Logical AND (&&), if the first fork() returns 0 (which it does for the child), the C compiler short-circuits and completely skips executing the second fork() for the child! You must draw a tree diagram to solve these safely.
