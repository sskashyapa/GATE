⏱️ Module 3: CPU Scheduling

FCFS, SJF, SRTF, Round Robin, and Priority Scheduling

1️⃣ The Golden Formulas (Memorize These!)

Every GATE numerical relies on perfectly understanding these 5 terms.

Term Definition Formula
Arrival Time (AT) Time when the process enters the Ready Queue. -
Burst Time (BT) Time required by the CPU to execute the process. -
Completion Time (CT) Time when the process fully completes execution. Read from right side of Gantt chart
Turnaround Time (TAT) Total time spent in the system (from arrival to completion). TAT = CT - AT
Waiting Time (WT) Total time spent waiting in the ready queue. WT = TAT - BT
Response Time (RT) Time from arrival until the FIRST time it gets the CPU. RT = (First CPU Allocation) - AT

2️⃣ Scheduling Algorithms

1. First Come First Served (FCFS)

Type: Non-Preemptive. Processes are executed in the exact order they arrive.

⚠️ GATE Trap: Convoy Effect

If a massive process (high BT) arrives first, all short processes behind it get stuck waiting. This plummets CPU utilization and skyrockets average waiting time.

2. Shortest Job First (SJF) / SRTF

Type: Can be Non-Preemptive (SJF) or Preemptive (SRTF - Shortest Remaining Time First).

The CPU always picks the process in the ready queue with the shortest remaining burst time.

🏆 Golden Rule: SJF gives the minimum average waiting time among all algorithms.

⚠️ GATE Trap: Starvation

Long processes may never get CPU time if short processes keep arriving. (Solution: Aging).

3. Round Robin (RR)

Type: Preemptive only. Designed for Time-Sharing systems.

Every process gets a fixed Time Quantum (TQ). If it doesn't finish, it gets preempted and pushed to the back of the Ready Queue.

If TQ is too large → Degrades to FCFS.
If TQ is too small → Massive context switch overhead.
