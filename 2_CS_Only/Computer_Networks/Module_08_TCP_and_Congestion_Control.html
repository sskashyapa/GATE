🚀 Module 8: Transport Layer & TCP Congestion Control

TCP Header Flags, 3-Way Handshake, Slow Start, Congestion Avoidance & RTT Traces

📖 Core Fundamental Theory: Process-to-Process Delivery

The Network Layer (IP) delivers packets from host to host. But once a packet reaches your laptop, which application should receive it: Chrome, Spotify, or Zoom? The Transport Layer provides Process-to-Process communication using Port Numbers (16-bit: 0 to 65,535).

Socket Address

A Socket is the software interface between an application and the network: Socket = IP Address + Port Number (e.g. 192.168.1.15:8080).

UDP (User Datagram Protocol)

Connectionless, lightweight, unreliable. 8-Byte fixed header (Source Port, Dest Port, Length, Checksum). Used for real-time traffic (DNS, VoIP, Gaming).

2️⃣ TCP Connection Management (3-Way Handshake)

Step 1: Client → Server SYN = 1, ACK = 0, SEQ = x   (Consumes 1 Seq No!)
Step 2: Server → Client SYN = 1, ACK = 1, SEQ = y, ACK_NUM = x + 1   (Consumes 1 Seq No!)
Step 3: Client → Server SYN = 0, ACK = 1, SEQ = x + 1, ACK_NUM = y + 1

TIME_WAIT State: After sending the final ACK during connection teardown (FIN handshake), the client waits for 2 × MSL (Maximum Segment Lifetime ≈ 2 minutes) before completely releasing the port to ensure the final ACK reached the server.

3️⃣ TCP Congestion Control (The Golden Numerical Topic)

TCP dynamically regulates how many bytes it sends into the network using the Congestion Window (cwnd). The actual sending window is: W = min(cwnd, rwnd).

The 3 Operational Phases:

1. Slow Start Phase (Exponential Growth)

Starts at cwnd = 1 MSS (Maximum Segment Size). For every successful ACK received, cwnd increases by 1 MSS → cwnd doubles every RTT (1, 2, 4, 8, 16...) until it reaches the threshold: ssthresh (Slow Start Threshold).

2. Congestion Avoidance Phase (Linear Growth / Additive Increase)

Once cwnd ≥ ssthresh, cwnd increases by only 1 MSS per RTT (e.g. 16 → 17 → 18 → 19 MSS) to probe for bandwidth safely.

3. Congestion Detection (Multiplicative Decrease)
Case A: Time Out (Severe Congestion)

• ssthresh = ⌊ cwnd / 2 ⌋
• cwnd resets to 1 MSS!
• Re-enters Slow Start.

Case B: 3 Duplicate ACKs (Mild Congestion)

• ssthresh = ⌊ cwnd / 2 ⌋
• cwnd = ssthresh (TCP Reno)
• Directly resumes in Congestion Avoidance!

Worked GATE Numerical Trace:

Start: cwnd = 1 MSS, ssthresh = 16 MSS. A Timeout occurs in Round 18 (when cwnd = 20 MSS).

Rounds 1 - 5 (Slow Start): cwnd = 1 → 2 → 4 → 8 → 16 MSS (hits threshold!)

Rounds 6 - 9 (Congestion Avoidance): cwnd = 17 → 18 → 19 → 20 MSS

Timeout at cwnd = 20: New ssthresh = 20 / 2 = 10 MSS, New cwnd = 1 MSS!

4️⃣ GATE Traps to Avoid

⚠️ TRAP 1: SYN & FIN consume Sequence Numbers, but ACK does NOT!

A segment with SYN=1 or FIN=1 consumes exactly 1 sequence number even if it carries 0 bytes of user data. A pure acknowledgment segment (SYN=0, FIN=0, Data=0) consumes 0 sequence numbers!

⚠️ TRAP 2: Sequence Number Wraparound Time

Since TCP sequence number is 32 bits, there are 232 possible bytes.
Formula for Wraparound Time: Twrap = 232 Bytes / Bandwidth (in Bytes/sec).
On a 1 Gbps (125 MB/s) link, sequence numbers wrap around in just: 232 / (125 × 106) ≈ 34.3 seconds!
