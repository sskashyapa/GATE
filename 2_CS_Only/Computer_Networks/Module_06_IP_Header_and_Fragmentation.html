📦 Module 6: IP Header, Fragmentation, ARP & ICMP

IPv4 Header Fields, Fragmentation Math (Offset in 8-byte units), MTU, IPv6 & Core Protocols

1️⃣ The IPv4 Datagram Header (20 to 60 Bytes)

Every field size and scaling factor is tested in GATE:

Bit 0 - 3 Bit 4 - 7 Bit 8 - 15 Bit 16 - 31
VER (4 bits) HLEN / IHL (4 bits) Type of Service (8 bits) Total Length (16 bits)
Identification (16 bits) Flags (3 bits) Fragment Offset (13 bits)
TTL (8 bits) Protocol (8 bits) Header Checksum (16 bits)
Source IP Address (32 bits)
Destination IP Address (32 bits)

• HLEN (Header Length): Measured in 4-byte words! Min value = 5 (5 × 4 = 20 Bytes), Max value = 15 (15 × 4 = 60 Bytes).

• Total Length: Total datagram length (Header + Data) in Bytes. Max = 216 - 1 = 65,535 Bytes. Payload = Total Length - (HLEN × 4).

• TTL (Time to Live): Decremented by 1 at every router hop. Prevents infinite looping. If TTL hits 0, router drops packet and sends ICMP Time Exceeded.

• Flags (3 bits):
  - Bit 0: Reserved (0).
  - Bit 1 (DF - Don't Fragment): 1 = Do not fragment.
  - Bit 2 (MF - More Fragments): 1 = More fragments follow; 0 = Last fragment.

• Protocol Numbers: 1 = ICMP, 6 = TCP, 17 = UDP, 89 = OSPF.

• Header Checksum: Protects only the header. Must be recomputed at every router because TTL changes!

2️⃣ IP Fragmentation Math

Every link layer technology has a Maximum Transmission Unit (MTU) (e.g., Ethernet MTU = 1500 bytes). If an incoming IP packet is larger than the outgoing link's MTU, the router must slice it into smaller fragments.

The 2 Golden Rules of Fragmentation:

  1. Payload Size must be a multiple of 8: Because Fragment Offset is 13 bits and represents 16-bit byte counts, it uses a scaling factor of 8. Every fragment's data payload (except possibly the very last one) must be divisible by 8!
    Max Data per Fragment = ⌊ (MTU - 20) / 8 ⌋ × 8
  2. Offset Formula: Fragment Offset = (Data Bytes sent before this fragment) / 8

Master Numerical:

A datagram of 4000 Bytes (20B Header + 3980B Data) arrives at a router with outgoing MTU = 1500 Bytes.

• Max data per fragment = ⌊ (1500 - 20) / 8 ⌋ × 8 = ⌊ 1480 / 8 ⌋ × 8 = 1480 Bytes.

Fragment Data Range Total Length Offset MF Flag
Frag 1 Byte 0 - 1479 1500 (20+1480) 0 / 8 = 0 1
Frag 2 Byte 1480 - 2959 1500 (20+1480) 1480 / 8 = 185 1
Frag 3 Byte 2960 - 3979 (1020B) 1040 (20+1020) 2960 / 8 = 370 0 (Last)

3️⃣ ARP, ICMP & NAT

ARP (Address Resolution)

Maps a known 32-bit IP address → 48-bit MAC address.

• ARP Request: Broadcasted to entire LAN (MAC FF:FF:FF:FF:FF:FF).
• ARP Reply: Unicast directly back to requester.

ICMP (Network Diagnostics)

Reports errors and operational information directly over IP (Protocol 1).

• ping: Uses Echo Request (Type 8) & Echo Reply (Type 0).
• traceroute: Intentionally sends packets with TTL = 1, 2, 3... to elicit ICMP Time Exceeded (Type 11).

NAT / PAT

Translates private IP addresses to a single public IP.

• Uses a NAT translation table mapping: (Private IP, Port) ↔ (Public IP, Port) so thousands of devices can share 1 public IP!

4️⃣ GATE Traps to Avoid

⚠️ TRAP 1: Reassembly is NEVER done by Intermediate Routers!

If a packet is fragmented at Router 1, Router 2 will NEVER assemble the fragments back together. Intermediate routers only fragment; Reassembly is strictly performed at the final Destination Host (because fragments can take different routes and arrive out-of-order!).

⚠️ TRAP 2: Scaling Factors: HLEN vs Offset

Remember:
• HLEN scaling factor = 4 (multiply HLEN by 4 to get Header Bytes).
• Fragment Offset scaling factor = 8 (multiply Offset by 8 to get starting Data Byte position).
