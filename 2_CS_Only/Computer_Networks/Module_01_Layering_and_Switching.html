🌐 Module 1: Layering & Switching Architecture

OSI vs TCP/IP Stacks, Switching Mechanisms, Network Delays & Bandwidth-Delay Product

📖 Core Fundamental Theory: Why Protocol Layering?

A computer network must handle physical voltages, error detection, finding paths across billions of routers, and delivering chat messages to specific browser tabs. Solving all of this in a single monolithic program would be an unmaintainable nightmare.

The Solution: Layered Architecture. Each layer provides a clean service to the layer above it, using services from the layer below it, while keeping its internal implementation hidden (Abstraction & Modularity).

Protocol Data Units (PDU) & Encapsulation

  • • Application Layer: Data / Message
  • • Transport Layer: Segment (TCP) / Datagram (UDP) [Adds Port numbers]
  • • Network Layer: Packet / Datagram [Adds IP addresses]
  • • Data Link Layer: Frame [Adds MAC addresses + CRC trailer]
  • • Physical Layer: Raw Bits (0s and 1s across electrical/optical signals)

OSI (7 Layers) vs TCP/IP (4/5 Layers)

The OSI model is a theoretical benchmark; the TCP/IP model is the actual working model of the Internet.

In TCP/IP, the top 3 OSI layers (Application, Presentation, Session) are collapsed into one single Application Layer.

GATE Rule: Presentation handles Syntax, Encryption & Compression. Session handles Dialog control & Checkpoints.

2️⃣ Layer Responsibilities & Types of Addresses

Layer Core Responsibility Addressing Scheme Devices Operating Here
Application (L7) Network services to user applications (HTTP, DNS, SMTP, FTP). Domain Names / URLs Gateways, Proxies
Transport (L4) End-to-End (Process-to-Process) communication, segmentation, flow/error control. Port Number (16-bit) Firewalls, End hosts
Network (L3) Host-to-Host delivery, Logical addressing, Routing across networks. Logical Address (IP: 32-bit v4, 128-bit v6) Routers, L3 Switches
Data Link (L2) Hop-to-Hop (Node-to-Node) delivery within same physical link, framing, MAC. Physical Address (MAC: 48-bit) Switches, Bridges, NIC
Physical (L1) Transmission of raw unstructured bits over physical medium. Modulation. - Hubs, Repeaters, Cables

3️⃣ Switching Architectures

How is data routed between source and destination when multiple paths exist?

Circuit Switching (e.g., Traditional Telephone)

  • 3 Phases: Connection Setup ➔ Data Transfer ➔ Connection Teardown.
  • Dedicated Bandwidth: Reserved resources along the entire path. No queuing delay during transfer.
  • Drawback: Inefficient for bursty traffic; wasted resources if channel is idle.

Packet Switching (The Internet Standard)

  • Data is broken into independent chunks called Packets.
  • Store-and-Forward: Each intermediate router must receive the entire packet before forwarding it.
  • Statistical Multiplexing: Resources shared on-demand; handles bursty internet traffic efficiently.
Datagram vs Virtual Circuit (VC) Packet Switching:

In Datagram packet switching (Connectionless, IPv4), each packet is treated independently and can follow different paths, arriving out-of-order. In Virtual Circuit packet switching (Connection-oriented, ATM/Frame Relay), a logical path is pre-established and all packets follow the same path in order.

4️⃣ Network Delays: The Golden Formulas

Almost every GATE question in Chapter 1 tests calculating one of these four components of total delay:

1. Transmission Delay (Tt)

Tt = L / B

Time taken by the transmitter to push all bits of the packet onto the transmission link.

  • • L: Length of packet in bits
  • • B: Bandwidth of link in bits/sec (bps)
  • • Depends only on packet size & link bandwidth (independent of distance!).

2. Propagation Delay (Tp)

Tp = d / v

Time taken for a single bit to travel from sender to receiver across the physical medium.

  • • d: Distance between sender and receiver in meters
  • • v: Velocity of signal (typically 2 × 108 m/s in copper/fiber, 3 × 108 m/s in air)
  • • Depends only on distance & medium speed (independent of packet size!).

3. Queuing Delay (Tq)

Time a packet spends waiting in router queues (buffers) before transmission. Depends on network congestion.

4. Processing Delay (Tproc)

Time router takes to examine packet header, check bit errors (checksum), and determine the outgoing link.

Total Point-to-Point Latency (Single Link)

Total Delay = Tt + Tp + Tq + Tproc

(Usually in GATE, unless specified, Tq and Tproc are assumed to be negligible/zero).

5️⃣ Bandwidth-Delay Product (BDP)

BDP measures the capacity of the link: how many bits can be "in flight" on the transmission wire simultaneously.

BDP = Bandwidth (B) × Propagation Delay (Tp)

Think of the link as a pipe: Bandwidth is the cross-sectional area, and Propagation Delay is the pipe length. BDP is the total volume of the pipe in bits!

6️⃣ Store-and-Forward with N Intermediate Routers

A source host sends a message of size M across N intermediate routers to reach the destination.

If there are N intermediate routers, the total number of hops (links) is N + 1.

• Single Packet Case: Total Time = (N + 1) × Tt + (N + 1) × Tp

• Pipelined Case (Message split into P packets): Total Time = (N + P) × Tt + (N + 1) × Tp

Why (N + P) × Tt? The first packet takes (N + 1) transmission steps to reach the destination. Every subsequent packet arrives just 1 transmission time step later due to pipelining!

7️⃣ GATE Traps to Avoid

⚠️ TRAP 1: Bandwidth is in Powers of 10, Storage in Powers of 2!

In networking:
• 1 Kbps = 103 bps = 1,000 bps
• 1 Mbps = 106 bps = 1,000,000 bps
• 1 Gbps = 109 bps
In RAM/Operating Systems, 1 KB = 1024 Bytes = 210 Bytes. Do NOT mix these up in network delay calculations!

⚠️ TRAP 2: Bits vs Bytes in Bandwidth (bps vs Bps)

Lowercase 'b' is bits. Uppercase 'B' is Bytes.
If a packet is 1 KB (1024 Bytes or 1000 Bytes depending on question) and bandwidth is 1 Mbps, always convert the packet length to bits:
L = 1000 × 8 bits before dividing by B = 10^6 bps!
