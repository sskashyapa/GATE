📬 Module 9: Application Layer Protocols

DNS Hierarchy & Queries, HTTP 1.0 vs 1.1 RTT Math, SMTP, POP3, IMAP & FTP

1️⃣ Domain Name System (DNS)

Translates human-readable domain names (gate.iitk.ac.in) into 32-bit IP addresses. Operates on Port 53 (Uses UDP for standard lookups, and TCP for Zone Transfers between DNS servers).

DNS Server Hierarchy:

• Root DNS Servers (.): 13 logical root server addresses worldwide.

• Top-Level Domain (TLD) Servers: Responsible for .com, .edu, .org, .in.

• Authoritative DNS Servers: An organization's official server storing its actual IP records.

• Local DNS Server (Resolver): Managed by your ISP or campus; caches records.

Common Resource Records (RR):

• A: Maps Hostname → 32-bit IPv4 address.

• AAAA: Maps Hostname → 128-bit IPv6 address.

• CNAME: Canonical Name (aliases: e.g. ftp.site.com → server1.site.com).

• MX: Mail Exchanger (specifies mail server for the domain).

• NS: Authoritative Name Server for the zone.

Recursive Query: The client asks the Local DNS server, and the Local DNS server performs all queries downstream on behalf of the client, returning the final answer.
Iterative Query: The queried server replies with: "I don't know the IP, but here is the IP of the next DNS server to ask!"

2️⃣ HTTP & Web Response Time Math

Runs over TCP Port 80 (HTTP) or Port 443 (HTTPS with TLS encryption). HTTP is inherently stateless (maintains state using Cookies).

Non-Persistent HTTP (HTTP/1.0)

Opens a brand new TCP connection for every single referenced object (images, CSS, JS) on a page.

Time per object = 2 × RTT + Ttrans

(1 RTT for TCP 3-way handshake + 1 RTT for HTTP Request/Data).

Persistent HTTP (HTTP/1.1)

Keeps the TCP connection open to fetch multiple objects across the same session.

  • • Without Pipelining: 1 RTT per referenced object.
  • • With Pipelining: Client sends requests for ALL objects back-to-back in 1 single RTT!
GATE Numerical Formula: For a base HTML file containing K referenced images:
  • Non-Persistent (HTTP/1.0): Total RTTs = 2 + 2K = 2(K + 1) RTTs.
  • Persistent without pipelining: Total RTTs = 2 + K RTTs (1 RTT for handshake + 1 RTT for base HTML + K RTTs).
  • Persistent with pipelining: Total RTTs = 2 + 1 = 3 RTTs total!

3️⃣ Electronic Mail Architecture

Email delivery involves distinct Push and Pull protocols:

SMTP (Port 25)

Push Protocol

Transfers mail from Sender → Sender's Mail Server → Recipient's Mail Server over TCP. Uses 7-bit ASCII (extended by MIME for multimedia attachments).

POP3 (Port 110)

Pull Protocol

Downloads messages from Mail Server to user's client machine. Simple, but does NOT synchronize changes or folders back to server.

IMAP (Port 143)

Pull Protocol

Modern sync protocol: maintains folder hierarchy directly on the server so emails stay in sync across phone, laptop, and webmail.

4️⃣ FTP (File Transfer Protocol)

FTP uses Two Separate Parallel TCP Connections (Out-of-band control):

Control Connection (Port 21)

Used for user authentication and directory navigation commands (USER, PASS, LIST). Remains open throughout the entire session (Persistent).

Data Connection (Port 20)

Created dynamically only when a file transfer (RETR, STOR) is initiated. Closed immediately after file finishes (Non-Persistent).

5️⃣ GATE Traps to Avoid

⚠️ TRAP 1: SMTP vs POP3/IMAP Roles

SMTP cannot pull mail! When you check your inbox, your client uses POP3 or IMAP. SMTP is used ONLY when pushing an email from client to server or between two servers.

⚠️ TRAP 2: DNS Uses BOTH UDP and TCP

Most people say DNS uses UDP. In GATE: DNS uses UDP (port 53) for queries because of speed (no connection setup), but uses TCP (port 53) for Zone Transfers between Primary and Secondary DNS servers because zone data must be 100% reliable!
