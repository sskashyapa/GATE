🗺️ Module 7: Routing Algorithms

Distance Vector (Bellman-Ford & Count-to-Infinity), Link State (Dijkstra), OSPF, RIP & BGP

📖 Core Fundamental Theory: Routing vs Forwarding

Forwarding (Data Plane)

The local, hardware-level action of transferring a packet from a router's input port to the appropriate output link interface based on the local Forwarding Table. (Takes nanoseconds).

Routing (Control Plane)

The network-wide software algorithm that calculates the optimal end-to-end paths packets take from source to destination, building the Forwarding Tables. (Takes seconds).

1️⃣ Distance Vector Routing (Bellman-Ford Algorithm)

In Distance Vector Routing, "Each router shares its knowledge of the entire network, but only with its directly connected immediate neighbors."

The Bellman-Ford Equation:

Let Dx(y) be the shortest distance from node x to node y:

Dx(y) = minv { c(x, v) + Dv(y) }

Where c(x, v) is the direct cost from x to neighbor v, and Dv(y) is neighbor v's reported distance to y.

⚠️ The Count-to-Infinity Problem:

DVR suffers from slow convergence when a link breaks: "Good news travels fast, bad news travels slowly."

If node A loses its direct link to node B, neighbor C still advertises that it can reach B in 2 hops. A assumes it can reach B through C (in 2 + 1 = 3 hops). C sees A's updated cost and increments its cost to 4, bouncing back and forth endlessly incrementing towards infinity!

1. Defining Infinity: RIP defines ∞ = 16 hops. Max path = 15 hops.
2. Split Horizon: Never advertise a route back to the neighbor you learned it from!
3. Poison Reverse: Advertise the route back with cost = ∞.

2️⃣ Link State Routing (Dijkstra's Algorithm)

In Link State Routing, "Each router shares its knowledge of its direct neighbors, but floods it to the ENTIRE network."

The 5 Steps of LSR:

  1. Discover immediate neighbors via HELLO packets.
  2. Measure link costs/delays to each neighbor via ECHO packets.
  3. Construct a Link State Packet (LSP) containing: Router ID, Sequence number, Age, and Neighbor list with costs.
  4. Reliable Flooding: Send LSP to all routers across the entire network.
  5. Run Dijkstra's Algorithm locally on the complete topological map to find shortest paths.

Advantages over DVR:

  • No Count-to-Infinity problem! Every router independently calculates paths using complete topology knowledge.
  • Rapid Convergence: As soon as a link state changes, flooding immediately alerts all nodes.
  • Protocol implementation: OSPF (Open Shortest Path First).

3️⃣ Routing Protocols Compared (GATE Reference)

Protocol Type Algorithm Metric Used Transport Layer Protocol
RIP (v1, v2) Intra-AS (IGP) Distance Vector (Bellman-Ford) Hop Count (Max = 15) UDP (Port 520)
OSPF Intra-AS (IGP) Link State (Dijkstra) Cost (108 / Bandwidth) Directly over IP (Protocol 89)

4️⃣ GATE Traps to Avoid

⚠️ TRAP 1: OSPF does NOT use TCP or UDP!

GATE loves to ask which transport protocol OSPF uses. RIP uses UDP (port 520) and BGP uses TCP (port 179), but OSPF uses neither! OSPF packets are encapsulated directly into IP datagrams with IP protocol field = 89.

⚠️ TRAP 2: BGP Loop Prevention Mechanism

BGP completely avoids count-to-infinity and routing loops by advertising the complete list of Autonomous System numbers in the AS-PATH attribute. If a border router receives an advertisement containing its own AS number in the path, it immediately detects a cycle and discards the route!
