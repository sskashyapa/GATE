🛡️ Module 2: Framing & Error Detection

Bit/Byte Stuffing, Checksums, CRC Polynomial Math & Hamming Code

📖 Core Fundamental Theory: Why Framing?

The Physical layer delivers an endless, uninterrupted stream of raw bits. The Data Link Layer must break this raw bit stream into discrete, manageable chunks called Frames so that receivers can recognize where one message begins and another ends.

1. Byte Stuffing (Character-Oriented)

Frames begin and end with a special FLAG byte. If the payload data itself contains the FLAG byte pattern, the sender inserts an Escape byte (ESC) right before it.

Original Data: A FLAG B ESC C Stuffed Data: FLAG A ESC FLAG B ESC ESC C FLAG

Receiver removes the ESC byte to recover the original payload.

2. Bit Stuffing (Bit-Oriented, e.g., HDLC)

Delimited by the universal flag pattern: 01111110 (0, followed by six 1s, followed by 0).

Rule: Whenever the sender detects five consecutive 1s in the data stream, it automatically injects a dummy 0 bit.

Data: 01111110 (contains six 1s) Stuffed: 011111010 (0 inserted after five 1s)

2️⃣ Error Detection Theory & Hamming Distance

Transmission media are imperfect; noise and electrical interference can flip bits (0 to 1 or 1 to 0). To detect errors, we append redundant check bits to the data.

Hamming Distance (d)

The number of bit positions in which two codewords differ (calculated by XORing the two codewords and counting the number of 1s).

Example: 10101 XOR 11100 = 01001 (Hamming distance = 2).

The Minimum Hamming Distance (dmin) Rules

  • • To detect up to e-bit errors: dmin ≥ e + 1
  • • To correct up to t-bit errors: dmin ≥ 2t + 1

Why? To correct errors, non-overlapping spheres of radius t around valid codewords must not intersect, requiring 2t + 1 distance!

3️⃣ Parity Checks: 1D vs 2D

Simple Parity (1D)

Appends 1 extra bit to ensure the total number of 1s is even (Even Parity) or odd (Odd Parity).

• Catches all odd number of bit errors (1, 3, 5 bit flips).
• Completely fails if an even number of bits flip (2, 4 bit errors cancel out).

Two-Dimensional (2D) Parity

Arranges data in a matrix; computes parity for every row AND every column.

• Detects ALL 1-bit, 2-bit, and 3-bit errors.
• Detects most 4-bit errors (fails only if 4 error bits form a perfect rectangle in the matrix!).
• Can correct single-bit errors (intersection of bad row & bad column).

4️⃣ Cyclic Redundancy Check (CRC) Polynomial Math

CRC treats bit strings as algebraic polynomials with binary coefficients (modulo-2 arithmetic). It is used in Ethernet, Wi-Fi, and ATM.

Step-by-Step CRC Algorithm:

  1. Let the data word be M (of length m bits).
  2. Let the Generator Polynomial be G(x) of degree k (so it has k + 1 bits).
  3. Append k zeros to the end of M (forming M · 2k).
  4. Perform Modulo-2 Division (binary division using XOR instead of subtraction) of the appended data by G(x).
  5. The remainder obtained is the CRC Checksum (FCS) of length k bits.
  6. Transmitted Codeword = Data bits + Remainder (replaces the appended zeros).
  7. Receiver Verification: Divide the received codeword by G(x). If Remainder == 0, no error detected!

Worked GATE Example:

Data M = 1010000, Generator G(x) = x3 + 1 → Binary: 1001 (Degree k = 3)

Append 3 zeros: 1010000000

Divide 1010000000 by 1001 via XOR:

 1010000000
^1001
-------
  011000000
 ^0000
-------
   11000000
  ^1001
-------
    1010000
   ^1001
-------
     011000 → Remainder after full division = 011

Transmitted Codeword = 1010000011

Error Detection Capabilities of CRC:

  • • Single bit errors: Detected if G(x) has at least 2 non-zero terms (xk + ... + x0).
  • • All odd numbers of errors: Detected if G(x) contains (x + 1) as a factor.
  • • Burst errors of length ≤ k: 100% detected!
  • • Burst error of length k + 1: Detected with probability 1 - (1/2)k-1.

5️⃣ Internet Checksum & Hamming Code

Internet Checksum (used in IP, TCP, UDP)

Data is treated as a sequence of 16-bit integers.

  1. Sum all 16-bit integers using 1's complement arithmetic (any carry out from the 16th bit is wrapped around and added to the sum).
  2. Take the 1's complement (NOT) of the final sum. This is the Checksum.
  3. Receiver adds all fields including checksum; result must be all 1s (0xFFFF).

Hamming Code (Error Correction)

Redundant parity bits r are placed at positions that are powers of 2 (positions 1, 2, 4, 8, 16...).

2r ≥ m + r + 1

Where m is data bits and r is redundant parity bits.

6️⃣ GATE Traps to Avoid

⚠️ TRAP 1: Number of Zeros to Append in CRC

If the generator is given as a polynomial: G(x) = x4 + x + 1, its degree is 4. You append exactly 4 zeros (degree k), NOT 5 zeros! The binary representation of G(x) is 10011 (5 bits), but the number of appended zeros is always equal to the highest exponent (k = 4).

⚠️ TRAP 2: Bit Stuffing Destuffing at Receiver

When destuffing, if the receiver sees 0111110, it removes the 0. But if it sees 01111110, that is NOT data—that is the closing FLAG byte indicating end of frame!
