🔄 Module 3: Flow & Error Control Protocols

Stop-and-Wait, Go-Back-N, Selective Repeat, Efficiency & Window Sizing Math

📖 Core Fundamental Theory: Flow vs Error Control

Flow Control (Rate Regulation)

Prevents a high-speed sender from overwhelming and crashing a slower receiver with more frames than its RAM buffers can process.

Error Control (Reliability)

Detects damaged or lost frames and handles automatic retransmission (Automatic Repeat reQuest - ARQ) via Acknowledgments (ACKs) and Timers.

Piggybacking: When a receiver has outgoing data of its own to send back to the sender, it attaches its ACK to the outgoing data frame instead of sending a separate ACK frame, saving bandwidth!

1️⃣ Stop-and-Wait ARQ

Sender transmits one single frame, starts a timer, and freezes until it receives an ACK. If the timer expires before ACK arrives, it retransmits the frame.

Timing Analysis & Efficiency Formula:

Total Cycle Time (T) = Transmission time of frame (Tt) + Propagation time to receiver (Tp) + Transmission time of ACK (Tack) + Propagation time of ACK back (Tp).

Since ACK frames are tiny (Tack ≈ 0), Total Time = Tt + 2Tp.

Normalized Delay Parameter (a):

a = Tp / Tt

Where Tp = d / v and Tt = L / B

Efficiency (η) & Throughput:

η = Tt / (Tt + 2Tp) = 1 / (1 + 2a)

Throughput = η × Bandwidth (B)

• Sequence Numbers Required: Exactly 2 numbers (0 and 1) → requires 1 bit for sequence number.
• Drawback: In high-speed long-distance links (high a, e.g., satellite links), Stop-and-Wait efficiency drops to < 1% because the transmitter sits completely idle waiting for ACKs!

2️⃣ Pipelining & Optimal Window Sizing

To achieve 100% efficiency (η = 1), the sender must continuously transmit frames during the entire round-trip time (Tt + 2Tp) without waiting for an ACK.

Optimal Window Size (Wopt): Wopt = 1 + 2a

If sender window size W ≥ 1 + 2a → Efficiency is 100% (link is completely saturated). If W < 1 + 2a → Efficiency η = W / (1 + 2a).

3️⃣ Go-Back-N (GBN) ARQ

Allows sender to transmit up to N frames before receiving an acknowledgment. The receiver has a window of size 1 (Wr = 1).

Key Properties

  • • Sender Window (Ws): N (at most 2k - 1 for k-bit sequence numbers).
  • • Receiver Window (Wr): Strictly 1 (discards out-of-order frames, no buffer!).
  • • Cumulative ACKs: ACK 5 acknowledges all frames up to 4.
  • • Single Timer: Maintained for the oldest unacknowledged frame.

The Retransmission Rule

If frame i is damaged or lost, the receiver rejects all subsequent frames (i+1, i+2...). When the timer for frame i expires, the sender must retransmit frame i AND all frames sent after it ("Go Back N")!

Wastes bandwidth if error rate is high.

Sequence Number Constraint: Ws + Wr ≤ 2k → Since Wr = 1, Ws ≤ 2k - 1.

4️⃣ Selective Repeat (SR) ARQ

Both sender and receiver maintain multi-frame windows. Only the damaged/lost frame is retransmitted.

Key Properties

  • • Sender Window (Ws): 2k-1.
  • • Receiver Window (Wr): Equal to Ws (2k-1).
  • • Out-of-order Buffering: Receiver accepts and buffers correct out-of-order frames!
  • • Independent (Selective) ACKs: Each frame is acknowledged individually.
  • • Individual Timers: Sender runs a separate timer for every outstanding frame.

Window Sizing Derivation

To prevent the receiver from confusing retransmitted old frames with brand-new frames from the next cycle:

Ws + Wr ≤ 2k

Since Ws = Wr: 2Ws ≤ 2k → Ws = Wr ≤ 2k-1

6️⃣ GATE Traps to Avoid

⚠️ TRAP 1: Sequence Number bits formula

If question asks: "A Go-Back-N protocol uses a window size of 7. How many bits are required in the sequence number field?"
Formula: Total sequence numbers = Ws + Wr = 7 + 1 = 8.
Bits = ⌈ log2(8) ⌉ = 3 bits.
If it were Selective Repeat with window 7: Total = 7 + 7 = 14 → ⌈ log2(14) ⌉ = 4 bits!

⚠️ TRAP 2: Half-Duplex vs Full-Duplex Efficiency

In Half-Duplex, the channel cannot transmit and receive simultaneously, so ACK transmission time (Tack) MUST be added to total cycle time: T = Tt + 2Tp + Tack. In Full-Duplex with piggybacking, Tack is effectively absorbed!
