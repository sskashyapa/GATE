📡 Module 4: Medium Access Control (MAC) & Ethernet

ALOHA, CSMA/CD Minimum Frame Size (L ≥ 2×Tp×B), Exponential Backoff & 802.3 Frame

📖 Core Fundamental Theory: The Multiple Access Problem

In point-to-point links (like an optical cable between two data centers), only one sender exists. But in broadcast media (like shared coaxial cables, Wi-Fi radio frequencies, or early hubs), multiple stations share the same physical channel.

If two or more stations transmit electrical/radio signals at the exact same time, the signals collide, distorting the waveforms into gibberish. The Medium Access Control (MAC) sublayer defines rules on who gets to transmit and when.

1️⃣ ALOHA Protocols

Developed at University of Hawaii for radio communication across islands.

Pure ALOHA (Continuous Time)

Stations transmit frames whenever data is ready. If a collision occurs, stations wait a random backoff time and retransmit.

  • • Vulnerable Time: 2 × Tt
  • • Throughput: S = G · e-2G
  • • Max Efficiency: 1 / (2e) ≈ 18.4% (at G = 0.5)

Slotted ALOHA (Discrete Time)

Time is divided into discrete slots equal to Tt. A station can ONLY transmit at the beginning of a time slot.

  • • Vulnerable Time: 1 × Tt (halved!)
  • • Throughput: S = G · e-G
  • • Max Efficiency: 1 / e ≈ 36.8% (at G = 1)

Note: G is the average number of attempted frame transmissions per frame-time Tt.

2️⃣ CSMA/CD (Carrier Sense Multiple Access with Collision Detection)

Used in classical Ethernet (IEEE 802.3). Stations sense the carrier before transmitting ("listen before talk") and continue monitoring the channel during transmission ("listen while talk").

The Fundamental Collision Detection Condition:

Suppose Station A transmits at t=0 towards Station B located distance d away. Just as the signal is about to reach B at time t = Tp - ε, Station B senses idle and transmits. The collision occurs near B, and the collision signal takes another Tp to travel back to A!

→ In the absolute worst case, Station A learns of the collision after 2 × Tp (Round Trip Time)!

To ensure A detects the collision before it finishes sending:

Tt ≥ 2 × Tp

Lmin ≥ 2 × Tp × Bandwidth (B)

Binary Exponential Backoff Algorithm:

When a collision occurs, how long should the station wait before retrying to prevent repeated collisions?

  • • After collision n (1 ≤ n ≤ 10), the station picks random integer K ∈ [0, 2n - 1].
  • • Waiting Backoff Time = K × Slot Time (where Slot Time = 2 × Tp).
  • • For collisions 11 to 15: K is frozen at [0, 210 - 1] = [0, 1023].
  • • If collision count reaches n = 16: Give up and report Network Failure!

3️⃣ Classic Ethernet (802.3) Frame Layout

Every field size must be memorized for GATE questions:

Preamble SFD Dest MAC Source MAC Length/Type Payload (Data) CRC (FCS)
7 Bytes 1 Byte 6 Bytes 6 Bytes 2 Bytes 46 to 1500 Bytes 4 Bytes
Minimum Frame Size: 6 + 6 + 2 + 46 + 4 = 64 Bytes.
Why 46 bytes min payload? 64 Bytes was chosen specifically so that at 10 Mbps over 2.5 km coaxial cable, Tt ≥ 2Tp holds true!
Maximum Frame Size: 6 + 6 + 2 + 1500 + 4 = 1518 Bytes.
(Preamble and SFD are physical layer synchronization bytes and are not counted towards the 64-1518 byte Ethernet frame limit).

4️⃣ CSMA/CA (Collision Avoidance - Wi-Fi 802.11)

Why not CSMA/CD in Wi-Fi? Because in wireless, a transmitter drowns out all incoming signals, making it impossible to detect collisions while transmitting, plus the Hidden Terminal Problem exists.

RTS / CTS Handshake:

Sender broadcasts a short Request To Send (RTS) frame. The Access Point replies with Clear To Send (CTS). All neighboring nodes overhear the CTS and silence themselves.

Inter-Frame Spacing (IFS):

Priority determined by idle wait duration:
SIFS (Shortest IFS): Highest priority, used for CTS/ACK.
DIFS (Distributed IFS): Longest IFS, used for regular data frames.

5️⃣ GATE Traps to Avoid

⚠️ TRAP 1: Upgrading Speed Changes Minimum Frame Size

Formula: Lmin = 2 × (d / v) × B.
If a network upgrades its bandwidth B from 10 Mbps to 100 Mbps (10× increase) without changing the frame size, maximum network distance d must be decreased by 10× (from 2500m to 250m) for collision detection to still work!

⚠️ TRAP 2: Collision Probability in Exponential Backoff

If two stations collide for the first time (n=1), both pick K ∈ {0, 1}. The probability of a second consecutive collision is P(both pick 0) + P(both pick 1) = (1/2 × 1/2) + (1/2 × 1/2) = 2/4 = 0.5 (50%)!
