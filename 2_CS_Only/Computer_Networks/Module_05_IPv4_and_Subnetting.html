🔢 Module 5: IPv4 Addressing, Subnetting & CIDR

Classful IP limits, Subnet Masks, Bitwise AND math, CIDR (/n) Prefix Rules & VLSM

📖 Core Fundamental Theory: Why IP Addressing?

Every network card has a unique 48-bit MAC address. Why can't the Internet just route packets using MAC addresses? Because MAC addresses are flat (non-hierarchical). If routers used MAC addresses, every single core router would need a routing table containing billions of entries (one for every smartphone and laptop on Earth!).

The Solution: Hierarchical IP Addressing (32-bit). Just like postal mail uses Country → State → City → House Number, an IP address splits into Network ID (NetID) and Host ID (HostID). Routers outside your city only look at the NetID to forward packets, keeping global routing tables tiny!

1️⃣ Classful Addressing (The Legacy System)

In original IPv4, the 32 bits were divided into 5 distinct classes based on the leading bits of the first byte (octet):

Class Leading Bits 1st Octet Range NetID / HostID Bits Default Mask Max Usable Hosts / Net
Class A 0... 0 - 127 8 / 24 255.0.0.0 (/8) 224 - 2 ≈ 16.7 Million
Class B 10... 128 - 191 16 / 16 255.255.0.0 (/16) 216 - 2 = 65,534
Class C 110... 192 - 223 24 / 8 255.255.255.0 (/24) 28 - 2 = 254
Class D 1110... 224 - 239 Reserved for Multicasting (No NetID/HostID)
Class E 1111... 240 - 255 Reserved for Experimental/R&D use

Special IP Addresses:

• Network Address: HostID bits are ALL 0s (e.g., 192.168.1.0). Used to identify the network itself.

• Directed Broadcast Address (DBA): HostID bits are ALL 1s (e.g., 192.168.1.255). Broadcasts to all hosts on that network.

• Limited Broadcast Address: 255.255.255.255 (all 32 bits are 1). Broadcasts to local LAN only; never forwarded by routers.

• Loopback Address: 127.0.0.0/8 (e.g., 127.0.0.1). Packets never leave the host's network card.

2️⃣ Subnetting: Borrowing Bits from HostID

Subnetting splits a single large network into multiple smaller, independent physical networks (subnets) inside an organization without acquiring new public IP blocks.

The Subnetting Formulas:

If an organization borrows s bits from the HostID:

Number of Subnets Created:

2s Subnets

Usable Hosts per Subnet:

2(h - s) - 2 Hosts

(-2 for Subnet Network ID & Subnet DBA)

How Routers Find the Subnet ID (Bitwise AND):

To determine which subnet an incoming packet belongs to, the router performs a Bitwise AND between the Destination IP and the Subnet Mask:

IP Address: 200. 10. 5. 68 → 11001000.00001010.00000101.01000100
Subnet Mask: 255.255.255.224 → 11111111.11111111.11111111.11100000 (/27)
---------------------------------------------------------------------------------
Bitwise AND: 200. 10. 5. 64 → 11001000.00001010.00000101.01000000 ← Subnet ID!

3️⃣ Classless Addressing (CIDR - Slash Notation)

Classful addressing caused massive address depletion (a company needing 300 hosts had to take a Class B block of 65,534 addresses, wasting 65,234!). CIDR abolished classes entirely in favor of arbitrary prefix lengths /n.

In a CIDR block a.b.c.d / n:

Total Addresses = 232 - n  |  Usable Hosts = 232 - n - 2

The 3 Mandatory Rules of a Valid CIDR Block (GATE Question Favorite):

  1. Rule 1 (Power of 2): Total addresses in the block must be a power of 2 (232-n).
  2. Rule 2 (Contiguous): All addresses must be continuous without any gaps.
  3. Rule 3 (Divisibility): The starting base address (in decimal) must be evenly divisible by the block size (i.e., its last 32 - n bits in binary must be ALL ZEROS).

4️⃣ Supernetting & Variable Length Subnet Masking (VLSM)

Supernetting (Route Aggregation)

Combines multiple smaller contiguous classful blocks into one single larger routing entry to shrink routing table size.

Example: Combining four /24 Class C blocks into one /22 supernet:
200.1.0.0/24, 200.1.1.0/24, 200.1.2.0/24, 200.1.3.0/24 → Aggregated Route: 200.1.0.0 / 22

VLSM (Variable Length Subnet Masking)

Instead of forcing every subnet to have the same mask, each department gets custom mask sizes matching its exact requirement.

Golden Rule: Always allocate the largest requirement first, then divide remaining space!

5️⃣ GATE Traps to Avoid

⚠️ TRAP 1: Valid vs Invalid Subnet Masks

A Subnet Mask MUST consist of contiguous 1s followed by contiguous 0s in binary!
• 255.255.240.0 → ...11110000.00000000 → VALID.
• 255.255.242.0 → ...11110010.00000000 → INVALID (has a 1 after a 0!).

⚠️ TRAP 2: Point-to-Point Links Need /30 Subnets

A router-to-router point-to-point link only has 2 hosts (the 2 router interfaces). You need 2 + 2 = 4 addresses → 22 = 4 → 32 - 2 = /30 mask (255.255.255.252). Never allocate a /29 or /28 to a point-to-point link!
