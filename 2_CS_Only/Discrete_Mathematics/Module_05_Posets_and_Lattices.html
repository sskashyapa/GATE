📐 Module 5: Posets, Hasse Diagrams & Lattices

Partial Orders, Maximal vs Greatest Elements, LUB/GLB, Distributive & Boolean Lattices

📖 Core Fundamental Theory: What is a Poset?

A relation R on a set A is a Partial Order if it satisfies 3 strict axioms: Reflexive, Antisymmetric, and Transitive (RAT). The pair (A, ≤) is called a Partially Ordered Set (Poset).

Standard Poset Examples:

  • (ℤ, ≤): Integers with "less than or equal to".
  • (P(S), ⊆): Power set with subset inclusion.
  • (Dn, |): Divisors of an integer n with divisibility.

Hasse Diagram (Simplified Graph)

To draw a Hasse diagram of a poset:
1. Delete all self-loops (Reflexivity understood).
2. Delete all transitive bypass edges.
3. Place smaller elements at bottom, larger elements on top with upward lines.

1️⃣ Extremal Elements in Posets

GATE frequently tests the difference between Maximal/Minimal vs Greatest/Least:

Top Elements:

• Maximal Element: An element m such that NO element is strictly greater than m. (A poset can have multiple maximal elements!).

• Greatest Element (Top / 1): An element G such that ∀x ∈ A, x ≤ G. (If it exists, it is strictly UNIQUE!).

Bottom Elements:

• Minimal Element: An element m such that NO element is strictly smaller than m. (A poset can have multiple minimal elements!).

• Least Element (Bottom / 0): An element L such that ∀x ∈ A, L ≤ x. (If it exists, it is strictly UNIQUE!).

LUB & GLB:
• LUB (Least Upper Bound / Join ∨): The smallest among all upper bounds of {a, b}.
• GLB (Greatest Lower Bound / Meet ∧): The largest among all lower bounds of {a, b}.

2️⃣ Lattices & Special Varieties

A poset (L, ≤) is a Lattice iff EVERY pair of elements {a, b} has a UNIQUE LUB (a ∨ b) and a UNIQUE GLB (a ∧ b).

1. Bounded Lattice

A lattice that has both a unique Least element (0) and a unique Greatest element (1). Every finite lattice is guaranteed to be bounded!

2. Distributive Lattice

Join and meet distribute over each other: a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c).

Invariant: A lattice is distributive iff it contains NEITHER the Pentagon lattice (N5) NOR the Diamond lattice (M3) as a sublattice!

3. Complemented Lattice

In a bounded lattice, every element a has a complement a' such that: a ∨ a' = 1 and a ∧ a' = 0.

4. Boolean Algebra (Boolean Lattice)

A lattice that is BOTH Distributive AND Complemented.

→ Cardinality Invariant: Every finite Boolean algebra has exactly 2k elements (2, 4, 8, 16...)!

3️⃣ GATE Traps to Avoid

⚠️ TRAP 1: Cardinality of Boolean Algebra MUST be a Power of 2!

If a GATE question asks: "Can a lattice with 6 elements (or 10, 12 elements) be a Boolean algebra?"
Answer is NO, NEVER! Any finite Boolean algebra is isomorphic to a power set lattice P(S), so its size must strictly be 2k (1, 2, 4, 8, 16, 32...).

⚠️ TRAP 2: Maximal ≠ Greatest!

A poset can have multiple maximal elements, but it can have at most ONE greatest element. If a poset has 2 or more maximal elements, it has NO greatest element!
