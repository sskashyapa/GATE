🔄 Module 8: Recurrence Relations

Characteristic Roots Method, Non-Homogeneous Particular Solutions & Master Theorem

📖 Core Fundamental Theory: What is a Recurrence Relation?

A Recurrence Relation expresses the n-th term of a sequence an recursively as a function of one or more previous terms (an-1, an-2, ...). The Degree / Order is the difference between the highest and lowest index (e.g. an = 5an-1 - 6an-2 has order 2).

1️⃣ Linear Homogeneous Recurrences (Characteristic Roots)

Equation of the form: c0 an + c1 an-1 + ... + ck an-k = 0.

Step 1: Write Characteristic Equation

Substitute an = rn → c0 rk + c1 rk-1 + ... + ck = 0

Step 2: Solve for Roots r

• Case 1: Distinct Real Roots (r1 ≠ r2):
  an = C1 (r1)n + C2 (r2)n

• Case 2: Repeated Real Roots (root r with multiplicity m):
  an = (C1 + C2n + C3n2 + ... + Cmnm-1) rn

Example: an = 5an-1 - 6an-2 with a0 = 1, a1 = 4.

1. Characteristic equation: r2 - 5r + 6 = 0 → (r - 2)(r - 3) = 0 → r1 = 2, r2 = 3.

2. General solution: an = C1(2n) + C2(3n).

3. Initial values: a0 = C1 + C2 = 1  |  a1 = 2C1 + 3C2 = 4.

Solving gives C1 = -1, C2 = 2 → an = 2(3n) - 2n.

2️⃣ Non-Homogeneous Recurrences: an = an(h) + an(p)

When the RHS is a non-zero driving function F(n), total solution = Homogeneous Solution + Particular Solution.

c · sn s is NOT a root A · sn

3️⃣ Master Theorem for Divide-and-Conquer Recurrences

For recurrences of the form: T(n) = a T(n / b) + Θ(nk logp n) (where a ≥ 1, b > 1):

Case 1: logb a > k

T(n) = Θ(nlogb a)

Case 2: logb a = k

T(n) = Θ(nk logp + 1 n)

Case 3: logb a < k

T(n) = Θ(nk logp n)

4️⃣ GATE Traps to Avoid

⚠️ TRAP 1: Never Apply Initial Conditions to Homogeneous Part Alone!

If solving a non-homogeneous recurrence an = an(h) + an(p), you MUST write down the complete solution an first, and THEN substitute a0, a1 to solve for constants C1, C2! Solving for constants before adding an(p) will give 100% wrong answers.

⚠️ TRAP 2: Resonance / Root Collision in Particular Solution

If the RHS is F(n) = 3n, but r = 3 was already a root of the homogeneous characteristic equation, your trial particular solution CANNOT be A · 3n! It must be multiplied by n → an(p) = A · n · 3n.
