🎲 Module 7: Combinatorics & Generating Functions

Permutations, Combinations, Stars & Bars Theorem & Ordinary Generating Functions

📖 Core Fundamental Theory: Sum vs Product Rule

Sum Rule (OR / Disjoint)

If task A can be done in m ways and task B can be done in n mutually exclusive ways, then task A OR B can be done in m + n ways.

Product Rule (AND / Sequence)

If a procedure consists of sequential subtasks where step 1 has m outcomes and step 2 has n outcomes, then the combined task has m × n outcomes.

1️⃣ Permutations vs Combinations

Permutation (Order Matters)

Arranging r distinct items from a set of n:

P(n, r) = n! / (n - r)!

• With duplicate items: n! / (n1! n2! ... nk!)
• Circular arrangements: (n - 1)!

Combination (Order Does NOT Matter)

Selecting r items from a set of n:

C(n, r) = n! / [r! (n - r)!]

• Symmetry identity: C(n, r) = C(n, n - r)
• Pascal's Identity: C(n, r) = C(n - 1, r) + C(n - 1, r - 1)

2️⃣ Stars & Bars Theorem (Distributing Identical Items)

Used to find the number of ways to distribute r identical objects into n distinct bins:

Case 1: Non-Negative Integers (xi ≥ 0)

Equation: x1 + x2 + ... + xn = r   (empty bins allowed)

C(n + r - 1, r) = C(n + r - 1, n - 1)

Case 2: Strictly Positive Integers (xi ≥ 1)

Equation: x1 + x2 + ... + xn = r   (every bin gets ≥ 1)

C(r - 1, n - 1)

(Placing n-1 divider bars into the r-1 gaps between stars!)

Worked GATE Problem:

How many non-negative integer solutions exist for: a + b + c + d = 12?

Here r = 12 (stars), n = 4 variables (bins).

Total Solutions = C(4 + 12 - 1, 12) = C(15, 12) = C(15, 3) = (15 × 14 × 13) / (3 × 2 × 1) = 455.

3️⃣ Ordinary Generating Functions (OGF)

An algebraic power series representing a discrete sequence: G(x) = a0 + a1x + a2x2 + ... = ∑ anxn.

Core Closed-Form Expansions:

1 / (1 - x) = 1 + x + x2 + x3 + ...

1 / (1 - ax) = 1 + ax + a2x2 + a3x3 + ...

(1 + x)n = ∑k=0n C(n, k) xk

The Multi-Choose Expansion:

1 / (1 - x)k = ∑n=0∞ C(n + k - 1, n) xn

The coefficient of xr in (1 - x)-k directly equals the Stars & Bars solution C(k + r - 1, r)!

4️⃣ GATE Traps to Avoid

⚠️ TRAP 1: The Stars & Bars Variables: n vs r

Always be clear about which number is the items and which is the bins:
• r = number of identical items (stars)
• n = number of distinct bins / variables
The formula is C(n + r - 1, r), NEVER C(r + n - 1, n)!

⚠️ TRAP 2: Lower Bound Offsets

If constraints specify x1 ≥ 2, x2 ≥ 3, x3 ≥ 0 for x1 + x2 + x3 = 15:
Substitute: y1 = x1 - 2 ≥ 0 and y2 = x2 - 3 ≥ 0.
New Equation: y1 + y2 + x3 = 15 - 2 - 3 = 10.
Now apply standard non-negative formula: C(3 + 10 - 1, 10) = C(12, 10) = 66!
