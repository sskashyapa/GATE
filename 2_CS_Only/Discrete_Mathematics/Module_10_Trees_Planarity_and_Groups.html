Cayley's Tree Formula, Euler's Planar Formula (V - E + R = 2), Kuratowski & Lagrange's Theorem

1️⃣ Trees & Spanning Tree Counting

A Tree is a connected, acyclic undirected graph. For any tree with n vertices, exactly |E| = n - 1 edges exist.

Fundamental Invariants:

• Unique simple path between every pair of vertices.

• Adding any single edge creates exactly one unique cycle.

• Removing any single edge disconnects the tree (every edge is a bridge!).

Cayley's Formula (Labeled Trees):

Number of distinct labeled spanning trees in a complete graph Kn:

T(n) = nn - 2

Example: For n = 4 → 44-2 = 42 = 16 trees.

2️⃣ Planar Graphs & Euler's Formula

A graph is Planar if it can be drawn in a 2D plane such that no two edges cross each other.

Euler's Formula for Connected Planar Graphs:

V - E + R = 2

(Where V = Vertices, E = Edges, R = Faces/Regions, including the unbounded exterior region!).

Standard Connected Planar (V ≥ 3):

Every face bounded by ≥ 3 edges → 2E ≥ 3R:

E ≤ 3V - 6

Triangle-Free Planar (No C3, e.g. Bipartite):

Every face bounded by ≥ 4 edges → 2E ≥ 4R:

E ≤ 2V - 4

Kuratowski's Theorem: A graph is planar iff it contains no subgraph homeomorphic to K5 (Complete graph on 5 vertices) or K3,3 (Utility graph / Complete bipartite on 3,3).

• K5 has V=5, E=10. But 3(5) - 6 = 9 < 10 → Non-Planar!
• K3,3 has V=6, E=9 (bipartite). But 2(6) - 4 = 8 < 9 → Non-Planar!

Lagrange's Theorem:

In any finite group G, the order of every subgroup H divides the order of G: |H| divides |G|.

• If |G| = p (prime), G has NO non-trivial proper subgroups, and G is strictly Cyclic and Abelian!

• Generators in a finite cyclic group of order n: exactly φ(n) generators exist!

4️⃣ GATE Traps to Avoid

⚠️ TRAP 1: The Exterior Region in Euler's Formula

When counting faces R in V - E + R = 2, do NOT forget the infinite outside region! If a planar drawing has 3 bounded interior circles, the total faces R is 3 + 1 = 4!

⚠️ TRAP 2: Subgroup Order Divisibility

If a group has size |G| = 24, can it have a subgroup of size 7?
By Lagrange's theorem, NO, because 7 does not divide 24! Possible subgroup sizes can ONLY be divisors: {1, 2, 3, 4, 6, 8, 12, 24}.
