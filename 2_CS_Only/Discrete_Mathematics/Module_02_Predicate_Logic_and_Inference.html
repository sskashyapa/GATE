🔍 Module 2: First-Order Predicate Logic & Inference

Quantifiers (∀, ∃), Nested Scopes, English Translation Rules & Resolution Proofs

📖 Core Fundamental Theory: Why Predicate Logic?

Propositional logic treats statements as indivisible atomic units (like P or Q). It cannot express relationships with variables like "x > 3" or generalize properties over sets like "All human beings are mortal".

First-Order Logic (Predicate Logic) introduces Predicates P(x), a Domain / Universe of Discourse, and Quantifiers (∀, ∃) to express complex mathematical reasoning.

1️⃣ The Two Quantifiers

Universal Quantifier (∀x P(x))

"For all x, P(x) is true."

  • • True iff P(x) is true for EVERY element in the domain.
  • • False if there exists even a single counterexample.
  • • Equivalent to finite AND: P(x1) ∧ P(x2) ∧ ... ∧ P(xn).

Existential Quantifier (∃x P(x))

"There exists an x such that P(x) is true."

  • • True iff P(x) is true for AT LEAST ONE element in the domain.
  • • False if P(x) is false for all elements in domain.
  • • Equivalent to finite OR: P(x1) ∨ P(x2) ∨ ... ∨ P(xn).

Negation Rules (De Morgan's for Quantifiers):

¬(∀x P(x)) ≡ ∃x ¬P(x)   |   ¬(∃x P(x)) ≡ ∀x ¬P(x)

2️⃣ Nested Quantifiers: Order of ∀ and ∃

While ∀x ∀y ≡ ∀y ∀x and ∃x ∃y ≡ ∃y ∃x, mixing ∀ and ∃ is NOT commutative!

∃y ∀x P(x, y)  ⇒  ∀x ∃y P(x, y)   (Converse is generally FALSE!)
∀x ∃y (x < y) (over Real Numbers):

"Given any real number x, there exists some real number y strictly greater than x." → TRUE (just pick y = x + 1).

∃y ∀x (x < y) (over Real Numbers):

"There exists a single universal number y that is greater than ALL real numbers x." → FALSE (No maximum real number exists!).

3️⃣ English to Logic Translations (The 4 Canonical Patterns)

Let A(x) = "x is a student" and B(x) = "x is smart":

English Sentence Correct Formalization Deadly GATE Trap (Wrong!)
"All students are smart" ∀x (A(x) → B(x)) ∀x (A(x) ∧ B(x)) ← (Means everyone on Earth is a student AND smart!)
"Some students are smart" ∃x (A(x) ∧ B(x)) ∃x (A(x) → B(x)) ← (Trivially true if someone is not a student!)
"No students are smart" ∀x (A(x) → ¬B(x)) ¬∀x (A(x) → B(x)) ← (Only means not ALL students are smart!)

4️⃣ Rules of Inference & Argument Validity

An argument with premises P1, P2, ... Pk and conclusion C is VALID if: (P1 ∧ P2 ∧ ... ∧ Pk) → C is a TAUTOLOGY.

Modus Ponens:

P, P → Q  ⊢  Q

Modus Tollens:

¬Q, P → Q  ⊢  ¬P

Hypothetical Syllogism:

P → Q, Q → R  ⊢  P → R

Disjunctive Syllogism:

P ∨ Q, ¬P  ⊢  Q

Resolution (Universal Rule):

P ∨ Q, ¬P ∨ R  ⊢  Q ∨ R

Resolution is refutation complete: to prove C, negate C (¬C), add it to premises, convert to CNF clauses, and derive the empty clause (□ / Contradiction)!

5️⃣ GATE Traps to Avoid

⚠️ TRAP 1: Never use ∧ with ∀, Never use → with ∃

• ∀x (A(x) ∧ B(x)) means EVERY entity in the universe has both properties.
• ∃x (A(x) → B(x)) evaluates to TRUE if there is just ONE entity in the universe for which A(x) is false (vacuous truth). It doesn't prove that any A actually exists!

⚠️ TRAP 2: Distributing ∀ over ∨ is INVALID!

• ∀ distributes over ∧: ∀x (P(x) ∧ Q(x)) ≡ (∀x P(x)) ∧ (∀x Q(x)) → VALID.
• ∀ does NOT distribute over ∨: ∀x (P(x) ∨ Q(x)) ≠ (∀x P(x)) ∨ (∀x Q(x)) → INVALID! (e.g. Every integer is either Even or Odd, but it is false that all integers are even or all are odd!).
