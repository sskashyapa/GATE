Power Sets, Cartesian Products, Venn Invariants & 3-Set PIE Formulas

📖 Core Fundamental Theory: Sets & Power Sets

A Set is an unordered collection of distinct objects. Cardinality |A| denotes the number of elements in set A.

Subsets vs Elements (⊆ vs ∈)

• x ∈ A: x is an element of A.
• A ⊆ B ⇔ ∀x (x ∈ A → x ∈ B): every element in A belongs to B.

• Empty set ∅ is a subset of EVERY set (∅ ⊆ A is universally true!).

Power Set P(A)

The set of all possible subsets of A, including ∅ and A itself.

• |P(A)| = 2n  (where |A| = n)

• |P(P(A))| = 22n

1️⃣ Set Operations & Symmetric Difference

Relative Difference (A - B):

A - B = A ∩ B̅

Elements in A that are NOT in B.

Symmetric Difference (A ⊕ B):

A ⊕ B = (A - B) ∪ (B - A)

       = (A ∪ B) - (A ∩ B)

Elements in A or B, but NOT in both!

Cartesian Product (A × B):

{(a, b) | a ∈ A, b ∈ B}

|A × B| = |A| × |B|

2️⃣ Principle of Inclusion-Exclusion (PIE)

To find the size of the union of multiple sets without double-counting overlaps:

Two Sets:

|A ∪ B| = |A| + |B| - |A ∩ B|

Three Sets (Master GATE Formula):

|A ∪ B ∪ C| = |A| + |B| + |C| - (|A ∩ B| + |B ∩ C| + |C ∩ A|) + |A ∩ B ∩ C|

Exactly One Set:

∑|A| - 2∑|A∩B| + 3|A∩B∩C|

Exactly Two Sets:

∑|A∩B| - 3|A∩B∩C|

At Least Two Sets:

∑|A∩B| - 2|A∩B∩C|

3️⃣ Classic GATE PIE Numerical (Divisibility)

Problem: How many integers between 1 and 1000 are divisible by 2, 3, or 5?

• |A| (divisible by 2) = ⌊1000 / 2⌋ = 500

• |B| (divisible by 3) = ⌊1000 / 3⌋ = 333

• |C| (divisible by 5) = ⌊1000 / 5⌋ = 200

• |A ∩ B| (divisible by lcm(2,3)=6) = ⌊1000 / 6⌋ = 166

• |B ∩ C| (divisible by lcm(3,5)=15) = ⌊1000 / 15⌋ = 66

• |A ∩ C| (divisible by lcm(2,5)=10) = ⌊1000 / 10⌋ = 100

• |A ∩ B ∩ C| (divisible by lcm(2,3,5)=30) = ⌊1000 / 30⌋ = 33

|A ∪ B ∪ C| = (500 + 333 + 200) - (166 + 66 + 100) + 33 = 1033 - 332 + 33 = 734.

4️⃣ GATE Traps to Avoid

⚠️ TRAP 1: The Power Set of Empty Set

• If A = ∅, then |A| = 0.
• The power set P(∅) = {∅} → |P(∅)| = 20 = 1 (it is NOT empty, it contains the empty set!).
• |P(P(∅))| = 21 = 2, and |P(P(P(∅)))| = 22 = 4.

⚠️ TRAP 2: ∅ ⊆ A vs ∅ ∈ A

• ∅ ⊆ A is ALWAYS TRUE for any set A.
• ∅ ∈ A is TRUE only if ∅ is explicitly written as an element inside A (e.g. A = {∅, 1, 2}).
