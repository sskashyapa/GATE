Injections, Surjections, Bijections, Stirling Numbers & Generalized Pigeonhole Math

📖 Core Fundamental Theory: Function Definitions

A function f: A → B assigns every single element of Domain A to EXACTLY ONE element of Codomain B. Let |A| = m and |B| = n.

1. Injective (1-to-1)

Distinct inputs give distinct outputs: f(a) = f(b) → a = b.

Requires: m ≤ n

2. Surjective (Onto)

Every element in codomain is mapped: Range = Codomain.

Requires: m ≥ n

3. Bijective

Both 1-to-1 AND Onto. Inverse function f-1 exists!

Requires: m = n

2️⃣ The Pigeonhole Principle (PHP) Math

Generalized PHP Formula

If N objects (pigeons) are distributed into k boxes (pigeonholes):

At least one box has ≥ ⌈ N / k ⌉ items

Guaranteed Category Selection (Reverse PHP)

Minimum items N to pick to GUARANTEE that at least r items belong to the same of k categories:

N = k × (r - 1) + 1

Worked GATE Problem:

How many cards must be selected from a standard 52-card deck (4 suits: Hearts, Spades, Diamonds, Clubs) to guarantee that at least 3 cards belong to the same suit?

Categories k = 4, Desired count r = 3.

N = 4 × (3 - 1) + 1 = 4 × 2 + 1 = 9 cards.

(Worst case: you pick 2 hearts, 2 spades, 2 diamonds, 2 clubs = 8 cards without hitting 3. The 9th card guarantees 3 of a suit!).

3️⃣ GATE Traps to Avoid

⚠️ TRAP 1: The Total Functions Exponent Order

Total functions from A to B is |B||A| (nm), NOT mn!
Why? Every single element in Domain A independently has n choices in Codomain B: n × n × ... (m times) = nm.

⚠️ TRAP 2: Onto Functions when m < n

If domain size is smaller than codomain size (m < n), it is mathematically impossible to cover all elements in codomain. The number of onto functions is 0!
