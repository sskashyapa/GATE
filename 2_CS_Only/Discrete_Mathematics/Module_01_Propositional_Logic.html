⚡ Module 1: Propositional Logic

Connectives, Truth Tables, Logical Equivalences, Tautologies & Normal Forms (CNF/DNF)

📖 Core Fundamental Theory: What is a Proposition?

A Proposition is a declarative statement that is either definitively TRUE (T) or definitively FALSE (F), but not both.

Valid Propositions:
  • "2 + 2 = 4" (True)
  • "The moon is made of green cheese" (False)
  • "New Delhi is the capital of India" (True)
NOT Propositions (Invalid):
  • "What time is it?" (Question)
  • "Please pass the salt" (Command / Request)
  • "x + 5 = 12" (Contains variable; truth value unknown)
  • "This statement is false" (Self-referential Paradox)

The Golden Implication Identity: P → Q ≡ ¬P ∨ Q

2️⃣ Variations of Conditional Statement P → Q

Converse: Q → P

Swapping hypothesis and conclusion. NOT equivalent to P → Q!

Inverse: ¬P → ¬Q

Negating both sides. Equivalent to the Converse, NOT to P → Q!

Contrapositive: ¬Q → ¬P

ALWAYS logically equivalent to P → Q! (Crucial for proofs).

3️⃣ Classification of Compound Propositions

Tautology (Valid)

Evaluates to TRUE under ALL possible truth assignments. (e.g. P ∨ ¬P).

Contradiction (Unsatisfiable)

Evaluates to FALSE under ALL possible truth assignments. (e.g. P ∧ ¬P).

Contingency

True for at least one assignment AND false for at least one assignment.

Satisfiable: A proposition is satisfiable if it is true for at least one row in its truth table. (All tautologies are satisfiable; contingencies can be satisfiable; only contradictions are unsatisfiable!).

4️⃣ Essential Equivalences for Simplification

De Morgan's Laws:

¬(P ∧ Q) ≡ ¬P ∨ ¬Q

¬(P ∨ Q) ≡ ¬P ∧ ¬Q

Distributive Laws:

P ∧ (Q ∨ R) ≡ (P ∧ Q) ∨ (P ∧ R)

P ∨ (Q ∧ R) ≡ (P ∨ Q) ∧ (P ∨ R)

Absorption Laws:

P ∨ (P ∧ Q) ≡ P

P ∧ (P ∨ Q) ≡ P

Exportation Law:

(P ∧ Q) → R ≡ P → (Q → R)

Biconditional Decomposition:

P ↔ Q ≡ (P → Q) ∧ (Q → P)

5️⃣ Functional Completeness (Minimal Sets)

A set of logical connectives is functionally complete if every possible truth table can be expressed using only those connectives.

Functionally Complete Sets:

{¬, ∧}, {¬, ∨}, {¬, →}, {NAND} alone, {NOR} alone.

NOT Functionally Complete:

{∧, ∨} (cannot produce NOT!), {⊕, ↔}, {¬}.

6️⃣ GATE Traps to Avoid

⚠️ TRAP 1: The False Hypothesis Trap (Vacuous Truth)

If hypothesis P is false, the implication P → Q is automatically TRUE regardless of what Q is! For example: "If 2 + 2 = 5, then the moon is made of cheese" is mathematically TRUE.

⚠️ TRAP 2: Operator Precedence Order

Without parentheses, evaluate in this strict order:
¬ (Highest) → ∧ → ∨ → → → ↔ (Lowest).
So P ∨ Q → R means (P ∨ Q) → R, NOT P ∨ (Q → R)!
