🕸️ Module 9: Graph Theory: Paths & Cycles

Handshaking Lemma, Bipartite Graphs, Eulerian Circuits, Hamiltonian Cycles & Coloring

1️⃣ The Handshaking Lemma & Degree Invariants

In every undirected graph G = (V, E), every edge contributes exactly 1 degree to each of its two endpoints:

∑v ∈ V deg(v) = 2 × |E|
Odd Degree Invariant:

In any undirected graph, the number of vertices having odd degree is ALWAYS EVEN! (If a degree sequence contains an odd number of odd values, that graph is impossible to draw!).

Regular Graphs (k-regular):

Every vertex has degree k → n × k = 2|E| → |E| = (n × k) / 2.

2️⃣ Bipartite Graphs (Odd Cycle Invariant)

A graph is Bipartite if its vertex set can be split into two disjoint sets V1, V2 such that every edge connects a vertex in V1 to V2.

The Golden Test for Bipartiteness:

A graph is Bipartite ⇔ It contains NO ODD CYCLES (no C3, C5, C7...)!

Complete Bipartite Graph Km, n:

Vertices: m + n  |  Edges: m × n.

Max Edges in Bipartite Graph (n vertices):

|E|max = ⌊ n2 / 4 ⌋

(Achieved when partitions are as equal as possible: ⌊n/2⌋ × ⌈n/2⌉).

3️⃣ Eulerian vs Hamiltonian Graphs (Edges vs Vertices)

Eulerian Graphs (Visits every EDGE once)

• Eulerian Circuit: Connected graph where EVERY vertex has an EVEN degree.

• Eulerian Path: Connected graph with EXACTLY 0 or 2 vertices of odd degree.

Decision problem is in P (Linear time check!).

Hamiltonian Graphs (Visits every VERTEX once)

• Hamiltonian Cycle: Closed cycle visiting every vertex exactly once. (NP-Complete!).

• Dirac's Theorem (Sufficient): If n ≥ 3 and deg(v) ≥ n / 2 for ALL vertices, then G is Hamiltonian.

• Ore's Theorem (Sufficient): If deg(u) + deg(v) ≥ n for all non-adjacent pairs (u, v), then G is Hamiltonian.

4️⃣ Graph Coloring & Gallai's Theorem

Chromatic Number χ(G):

Minimum colors to color vertices so no adjacent vertices share a color.

• Complete Graph Kn: χ(Kn) = n

• Bipartite Graph: χ(G) = 2 (iff it has at least 1 edge)

• Cycle Cn: χ(Cn) = 2 if n even, 3 if n odd.

Gallai's Identity:

Let α(G) = Maximum Independent Set size.

Let β(G) = Minimum Vertex Cover size.

α(G) + β(G) = |V|

5️⃣ GATE Traps to Avoid

⚠️ TRAP 1: Eulerian Circuit vs Path Odd Degrees

• For an Euler Circuit (returns to start), you need 0 odd-degree vertices.
• If a graph has 2 odd-degree vertices, it has an Euler Path (starts at one odd vertex, ends at the other), but NO Euler Circuit!
• If a graph has 4 odd-degree vertices, it has NEITHER an Euler Path NOR an Euler Circuit!

⚠️ TRAP 2: Dirac's Theorem is SUFFICIENT, NOT Necessary!

If a graph does NOT satisfy deg(v) ≥ n/2, you CANNOT conclude it is not Hamiltonian! For example, a simple cycle C10 has deg(v) = 2 < 5 for all vertices, yet it is obviously Hamiltonian!
