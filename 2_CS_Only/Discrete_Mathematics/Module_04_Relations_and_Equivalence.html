Relation Properties, Counting Formulas (2n²), Equivalence Partitions & Bell Numbers

📖 Core Fundamental Theory: What is a Relation?

A binary relation R from set A to set B is a subset of the Cartesian product: R ⊆ A × B. If both sets are the same, R ⊆ A × A is a relation on set A.

If |A| = n, then |A × A| = n2. Since a relation is any subset of A × A, the total number of relations on A is 2n².

1️⃣ The Core Properties of Relations

1. Reflexive

Every element is related to itself: ∀x ∈ A, (x, x) ∈ R.

Formula: 2n(n - 1) = 2n² - n

2. Irreflexive

NO element is related to itself: ∀x ∈ A, (x, x) ∉ R.

Formula: 2n² - n

Note: Irreflexive is NOT the opposite of reflexive!

3. Symmetric

If (x, y) ∈ R, then (y, x) MUST be in R: (x, y) ∈ R → (y, x) ∈ R.

Formula: 2n(n + 1) / 2

4. Antisymmetric

If (x, y) ∈ R and (y, x) ∈ R, then x MUST equal y! (No distinct bidirectional pairs).

Formula: 2n × 3n(n - 1) / 2

5. Asymmetric

If (x, y) ∈ R, then (y, x) CANNOT be in R (strictly irreflexive & antisymmetric).

Formula: 3n(n - 1) / 2

6. Transitive

If (x, y) ∈ R and (y, z) ∈ R, then (x, z) MUST be in R.

No simple closed formula (tested via path reachability).

3️⃣ Equivalence Relations & Bell Numbers

A relation R is an Equivalence Relation if it is Reflexive, Symmetric, and Transitive (RST).

The Partition Theorem: Every equivalence relation partitions set A into non-empty, pairwise disjoint Equivalence Classes whose union equals A!

The number of equivalence relations on a set of size n equals the number of partitions of that set → Bell Number B(n):

4️⃣ GATE Traps to Avoid

⚠️ TRAP 1: The Empty Relation ∅ on a Non-Empty Set

The empty relation ∅ is:
• Symmetric: YES (no counterexample where (x,y) ∈ ∅ and (y,x) ∉ ∅).
• Antisymmetric: YES.
• Asymmetric: YES.
• Transitive: YES.
• Irreflexive: YES.
• Reflexive: NO! (Unless set A = ∅).

⚠️ TRAP 2: Symmetric vs Antisymmetric are NOT Opposites

A relation can be both Symmetric and Antisymmetric at the same time! If R contains only diagonal elements (e.g. R = {(1, 1), (2, 2)}), it is both symmetric AND antisymmetric.
